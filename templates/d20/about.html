Behind the table

Source code

A Django project with server-rendered templates, plain CSS and JavaScript. A little htmx keeps search responsive.

  • Python
  • Django
  • htmx
  • PostgreSQL
  • SQLite

Made for a shared table

  • Guests can browse campaigns. An account opens player details and session locations.
  • Campaign notes are shared with campaign members.
  • Local development uses SQLite; production uses PostgreSQL.
  • Application tests, type checking and code style checks accompany the project.
